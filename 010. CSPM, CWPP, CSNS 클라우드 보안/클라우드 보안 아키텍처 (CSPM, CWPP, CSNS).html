클라우드 보안 아키텍처 실무

CSPM, CWPP, CSNS의 구조와 통합 보안 전략

1. CSPM (Cloud Security Posture Management, 클라우드 보안 태세 관리)

CSPM은 클라우드 인프라의 설정 오류를 감지하고 규정 준수(Compliance)를 모니터링하는 보안 솔루션입니다. 주로 API 기반으로 동작하며 '설계도'가 올바른지 검사합니다.

아키텍처 해설

  • API 기반 가시성: 에이전트 설치 없이 클라우드 서비스 제공자의 API를 호출하여 전체 리소스의 상태를 파악합니다.
  • 지속적 컴플라이언스: CIS Benchmark, ISMS-P 등 국내외 표준에 맞춰 실시간으로 설정을 대조합니다.
  • 자동 치료(Remediation): 보안 그룹이 0.0.0.0/0으로 개방되는 등 위험 감지 시 즉시 차단하거나 설정을 원복합니다.
  • 관련 유료 서비스: AWS Security Hub유료, AWS Config유료

2. CWPP (Cloud Workload Protection Platform, 클라우드 워크로드 보호 플랫폼)

CWPP는 클라우드에서 실행되는 실제 '작업 단위(Workload)' 내부를 보호합니다. 가상 머신(EC2), 컨테이너, 서버리스 함수 내부의 악성코드나 취약점을 방어합니다.

아키텍처 해설

  • 에이전트/사이드카 구조: 워크로드 내부에 에이전트를 설치하여 시스템 콜을 모니터링하고 이상 행위를 탐지합니다.
  • 가시성(Visibility): 인프라 설정이 아닌, 실행 중인 애플리케이션의 프로세스, 네트워크 연결, 파일 변경을 감시합니다.
  • 취약점 관리: OS 패치 수준, 설치된 패키지의 CVE(Common Vulnerabilities and Exposures, 취약점 식별 번호)를 분석합니다.
  • 관련 유료 서비스: Amazon GuardDuty유료, Amazon Inspector유료

3. CSNS (Cloud Service Network Security, 클라우드 서비스 네트워크 보안)

CSNS는 클라우드 네트워크의 경계와 내부 통신을 보호하는 전통적인 네트워크 보안 기술의 클라우드 버전입니다. 방화벽, IPS, WAF 등이 여기에 해당합니다.

아키텍처 해설

  • 인그레스/이그레스 제어: 외부에서 들어오는 트래픽(Ingress)과 나가는 트래픽(Egress)에 대해 정밀한 필터링을 수행합니다.
  • 마이크로 세그멘테이션: VPC 내부에서 서버 간의 통신(East-West 트래픽)을 잘게 나누어 보안 사고 발생 시 전파 범위를 최소화합니다.
  • 차세대 방화벽: 단순 포트 차단을 넘어 SSL 복호화 및 애플리케이션 식별 기능을 제공합니다.
  • 관련 유료 서비스: AWS Network Firewall유료, AWS WAF유료, AWS Shield Advanced유료

보안 솔루션 비교 요약

구분 CSPM CWPP CSNS

핵심 가치 컴플라이언스, 설정 오류 방지 위협 탐지, 취약점 관리 침입 차단, 가용성 확보
