## 타켓서버만들기

우분투 14.04.6 desktop    ** cli 터미널 모드 변경  ctrl + Alt +F3
아파치 2.2.8
mysql 5.0.51a 




버전 고정 방법
```
# 1. 현재 사용 중인 커널 관련 패키지들 고정 (가장 중요)
sudo apt-mark hold linux-image-$(uname -r)
sudo apt-mark hold linux-headers-$(uname -r)
sudo apt-mark hold linux-image-extra-$(uname -r)

# 2. 우분투 배포판 버전 정보를 담은 패키지 고정
sudo apt-mark hold base-files
```

옛날 버전 저장소 주소 변경
# 저장소 주소를 old-releases로 변경
sudo sed -i 's/archive.ubuntu.com/old-releases.ubuntu.com/g' /etc/apt/sources.list
sudo sed -i 's/security.ubuntu.com/old-releases.ubuntu.com/g' /etc/apt/sources.list
sudo sed -i 's/kr.archive.ubuntu.com/old-releases.ubuntu.com/g' /etc/apt/sources.list

# 패키지 리스트 업데이트
sudo apt update
